# 0.1.15 — 2026-08-22

## Changed

- **MCP transport** now uses the SDK v2 framework path, serves HTTP protocol revision 2026-07-28 alongside the supported 2025 revision, rejects undeclared top-level tool arguments, and advertises tool failure envelopes in output schemas.
- **`MCP_SESSION_MODE`** is explicitly `stateless` in the container, example environment file, and configuration reference.
- **`socrata_dataframe_describe`** no longer claims to return a registration time that its result does not contain.

## Fixed

- **Resource responses** — `socrata://datasets/{domain}/{datasetId}` and `socrata://portals` now advertise output schemas matching their returned JSON.
- **Generic Socrata HTTP errors** preserve the framework's canonical `status` and `body` fields after Socrata-specific error inspection.

- `@duckdb/node-api` `^1.5.4-r.1` → `^1.5.5-r.4`
