# 0.1.12 — 2026-07-04

## Added

- **`@duckdb/node-api`** — added as a regular dependency (`^1.5.4-r.1`), so the dataframe tools (`socrata_dataframe_describe`, `socrata_dataframe_query`) and canvas spillover work out of the box wherever `CANVAS_PROVIDER_TYPE=duckdb` is set, with no manual peer install. The `.mcpb` bundle grows from ~5.5 MB to ~39 MB carrying the build-platform DuckDB binding. ([#17](https://github.com/cyanheads/socrata-mcp-server/issues/17))

## Changed

- **`KNOWN_PORTALS`** — refreshed from 36 to 40 entries: pruned 17 domains no longer resolving in the Discovery catalog (`404 Domain not found`), added 21 live-verified portals (probed via `?domains=<domain>&only=dataset&limit=0`, 200 with `resultSetSize`). `socrata_list_portals`, the `socrata://portals` resource, and README portal-count references updated to match. ([#18](https://github.com/cyanheads/socrata-mcp-server/issues/18))
- **README** / **`docs/design.md`** — canvas and DataCanvas wording now says DuckDB is bundled, not a peer install. ([#17](https://github.com/cyanheads/socrata-mcp-server/issues/17))
