# 0.6.1 — 2026-11-03

## Added

- **`asset_type` and `parent_dataset_ids`** on `socrata_find_datasets` results (#68): `asset_type` names the catalog type (dataset, filter, map, chart, story, href, and so on); `parent_dataset_ids` lists the assets it is built from. Both are omitted when the catalog lists none.
- **`asset_type`** on `socrata_get_dataset` and the `socrata://datasets/{domain}/{datasetId}` resource (#68).
- **`stage`** on `socrata_query_dataset` (#69, default `true`): `false` returns the page without sending the staging request or acquiring a canvas; `canvas_id` and `table_name` then go unused and the notice says so.

## Changed

- **`dataset_id`** on `socrata_get_dataset` and `socrata_query_dataset`, and the dataset resource's `datasetId` (#67): advertises a case-insensitive four-by-four `pattern` and is lowercased, so `KZJM-XKQJ` now resolves. On the two tools a malformed ID fails input validation (`-32602`) instead of `invalid_id`; the resource still answers one with `-32007` (`ValidationError`), now with a message naming the four-by-four form and `socrata_find_datasets`.
- **`openWorldHint`** (#67): `true` on `socrata_get_dataset`, `socrata_query_dataset`, and `socrata_list_portals`; `false` on `socrata_dataframe_describe` and `socrata_dataframe_query`.
- **`socrata-guide` skill 1.0.1 → 1.0.2**: covers `asset_type`, `stage`, and the `domain` requirement for `tags` and `categories`.

## Fixed

- **Invalid environment values** (#62): `SOCRATA_*` and `MCP_*` values that fail validation now stop startup with the banner naming the variable, under Bun and Node, instead of a raw stack trace. Server config is parsed in `setup()`, not at module import.
- **Map, chart, calendar, and visualization assets** (#64): `socrata_query_dataset` fails them `not_tabular` before any recount or staging, instead of returning empty objects as rows. The recovery names the tables the asset is built on when the catalog lists them, and otherwise points to `socrata_find_datasets` with `only: "datasets"`.
- **`tags` and `categories` without `domain`** (#65): `socrata_find_datasets` fails `domain_required` before any request, since both match one portal's own vocabulary. An empty array or a blank entry reads as unset.
- **`socrata_dataframe_query` table cells** (#66): STRUCT, MAP, and LIST values render as JSON in the `content[]` table, not `[object Object]` or a comma-join.
