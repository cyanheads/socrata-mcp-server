# 0.6.1 — 2026-11-03

## Added

- **`asset_type` and `parent_dataset_ids`** on `socrata_find_datasets` results (#68): `asset_type` names the catalog type (dataset, filter, map, chart, story, href, and so on); `parent_dataset_ids` lists the assets it is built from. Both are omitted when the catalog lists none.
- **`asset_type`** on `socrata_get_dataset` and the `socrata://datasets/{domain}/{datasetId}` resource (#68).
- **`stage`** on `socrata_query_dataset` (#69, default `true`): `false` returns the page without sending the staging request or acquiring a canvas; `canvas_id` and `table_name` then go unused and the notice says so.

## Changed

- **`dataset_id`** on `socrata_get_dataset`, `socrata_query_dataset`, and the dataset resource's `datasetId` (#67): advertises a case-insensitive four-by-four `pattern` and is lowercased, so `KZJM-XKQJ` now resolves. A malformed ID fails input validation (`-32602`) instead of `invalid_id`.
- **`openWorldHint`** (#67): `true` on `socrata_get_dataset`, `socrata_query_dataset`, and `socrata_list_portals`; `false` on `socrata_dataframe_describe` and `socrata_dataframe_query`.
- **`socrata-guide` skill 1.0.1 → 1.0.2**: covers `asset_type`, `stage`, and the `domain` requirement for `tags` and `categories`.

## Fixed

- **Invalid environment values** (#62): `SOCRATA_*` and `MCP_*` values that fail validation now stop startup with the banner naming the variable, under Bun and Node, instead of a raw stack trace. Config is read in `setup()`, not at module import.
- **Map, chart, calendar, and visualization assets** (#64): `socrata_query_dataset` fails them `not_tabular`, naming the parent table when the catalog lists one, instead of returning empty objects as rows.
- **`tags` and `categories` without `domain`** (#65): `socrata_find_datasets` fails `domain_required` before any request, since both match one portal's own vocabulary. An empty array or blank entries still read as unset.
- **`socrata_dataframe_query` table cells** (#66): STRUCT, MAP, and LIST values render as JSON in the `content[]` table, not `[object Object]` or a comma-join.

## Dependencies

- `tsc-alias` ^1.9.9 → ^1.9.10 (dev)
- `vitest` ^5.0.5 → ^5.1.0 (dev)
