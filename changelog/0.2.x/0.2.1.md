# 0.2.1 — 2026-09-22

## Added

- **`socrata_query_dataset` `table_name`** — new output field naming the staged canvas table on a spill; the post-spill truncation notice now names it plus both dataframe tools in one message. [#30](https://github.com/cyanheads/socrata-mcp-server/issues/30)

## Fixed

- **`content[]` rendering** — `socrata_get_dataset`, `socrata_find_datasets`, and `socrata_dataframe_query` render descriptions and executed SQL in full instead of truncating at 2000/400/200 characters; `content[]` now matches `structuredContent`. [#19](https://github.com/cyanheads/socrata-mcp-server/issues/19)
- **`assembled_query`** now includes `$offset` when paginating past the first page instead of silently omitting it. [#24](https://github.com/cyanheads/socrata-mcp-server/issues/24)
- **Canvas spill typing** — `socrata_query_dataset` spills register an explicit schema from the `X-SODA2-Fields`/`X-SODA2-Types` response headers (SODA `number` → `DOUBLE`) instead of a 100-row DuckDB sniff, so numeric comparisons need no cast and columns null in the first 100 rows still stage. A small `limit` still stages the full 50,000-row copy. [#25](https://github.com/cyanheads/socrata-mcp-server/issues/25)
- **`socrata_dataframe_describe`** no longer promises a registration time the tool never returned; `docs/design.md` matches. [#26](https://github.com/cyanheads/socrata-mcp-server/issues/26)
