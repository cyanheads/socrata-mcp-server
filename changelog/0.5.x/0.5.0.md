# 0.5.0 — 2026-10-28

## Added

- **Socrata guide resources**: `skill://socrata-guide/SKILL.md` and its query-syntax reference cover dataset coverage checks and SoQL/DuckDB analysis.
- **Agent Plugins manifests**: root `plugin.json` and `mcp.json` supply the stdio server configuration alongside the existing client overlays.

## Changed

- **Guide delivery**: the published guide ships through npm, Docker, plugin installs, and the MCPB bundle.
- **Framework adoption**: 0.13.17–0.13.18 bring atomic canvas table replacement, HTTP request signal cleanup, and discovery search echoes rendered as code literals without Markdown escapes.
- **Development tooling**: refresh framework references, packaging validation, the bug-report form, and install documentation; align Bun's minimum release age to one day.

## Fixed

- **Desktop bundles**: preserve nested MCP SDK runtime skill modules while stripping package-root agent documentation, node-gyp build output, and build-only package files ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
- **Empty-result notices**: render caller filters and WHERE clauses as literal text without changing the query sent upstream.
