# 0.4.0 — 2026-10-24

## Changed

- **`socrata_dataframe_query`** now rejects `query_table()`, dynamically constructed `query()` SQL, and unqualified `current_schema` columns; use direct table references, literal SQL, or qualified columns.
- **Engine-setting functions** (`current_schema()`, `current_setting()`, `current_schemas()`, `in_search_path()`) are rejected by the adopted SQL policy; query staged data instead.
- **DataCanvas** is enabled by default when `CANVAS_PROVIDER_TYPE` is unset, blank, or an unresolved placeholder; explicit `none` disables it. The portable MCPB bundle sets `none` because it excludes native DuckDB bindings.
- **Framework tooling and docs** refresh audit classification, framework references, startup configuration examples, and hosted-client connection instructions.

## Fixed

- **`socrata_query_dataset`** reports `not_tabular` for SODA's non-tabular asset response, with recovery directing callers to dataset-only search. ([#42](https://github.com/cyanheads/socrata-mcp-server/issues/42))
- **Canvas table names** gain a `t_` prefix for digit-leading dataset IDs, allowing their result sets to stage and remain queryable. ([#44](https://github.com/cyanheads/socrata-mcp-server/issues/44))
- **Gateway query refusals** receive one bounded bare-row diagnostic after same-portal catalog confirmation; a successful control yields `query_rejected` with SoQL guidance, while inconclusive controls preserve the original classification and caller cancellation propagates. ([#45](https://github.com/cyanheads/socrata-mcp-server/issues/45))
- **Portal-authored text** renders Markdown punctuation literally in dataset names, descriptions, metadata, and table cells.
